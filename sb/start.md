# Erste Schritte

## Deine Insel erstellen

{% stepper %}
{% step %}
#### Verbinden

Betritt den Server über `megabuild.de` (Bedrock: Port `19132`). Auf der Java Edition musst du das Resourcepack annehmen.

{% content-ref url="../ag/join.md" %}
[join.md](../ag/join.md)
{% endcontent-ref %}
{% endstep %}

{% step %}
#### Skyblock-Menü öffnen

Du landest in der Lobby. Gib `/sky` ein oder klicke den Skyblock-NPC an und wähle **Skyblock erstellen**.
{% endstep %}

{% step %}
#### Startbiom wählen

Wähle, in welcher Landschaft deine Insel beginnt. **Diese Wahl kannst du später nicht mehr ändern.** Alle anderen Biome schaltest du im Spiel frei.

| Kategorie | Deine Startinsel |
| --------- | ---------------- |
| Ebenen | Ebene |
| Wälder | Wald |
| Schnee & Eis | Schneeebene |
| Wüste & Steppe | Wüste |
| Dschungel | Lichter Dschungel |
| Gebirge | Windschliff-Hügel |
| Gewässer | Fluss |
| Sumpf & Selten | Sumpf |
{% endstep %}

{% step %}
#### Kurz warten

Deine Insel wird jetzt als eigener Server gestartet. Über deiner Schnellleiste siehst du den Fortschritt. Sobald alles bereit ist, wirst du automatisch verbunden.
{% endstep %}
{% endstepper %}

## Ankunft mit dem Luftschiff

Bei deinem ersten Besuch kommst du mit einem **Luftschiff** an. Guide **Moony** erzählt dir unterwegs die Geschichte der neuen Welt. Du kannst dich an Deck frei bewegen – springst du über Bord, landest du wieder auf dem Schiff.

Auf dem Schiff wartet auch dein erstes **Warpett**. So kommst du vom Schiff auf deine Insel:

{% stepper %}
{% step %}
#### Löwenzahn pflücken

Pflücke den Löwenzahn an Deck.
{% endstep %}

{% step %}
#### Dem Warpett geben

Nimm den Löwenzahn in die Hand und klicke das Warpett auf dem Schiff mit **Rechtsklick** an. Es frisst die Blume und verbindet sich mit dem Warpett auf deiner Startinsel.
{% endstep %}

{% step %}
#### Reisen

Klicke das Warpett erneut an – es bringt dich auf deine Startinsel. Genauso kommst du jederzeit zurück aufs Schiff.
{% endstep %}
{% endstepper %}

{% content-ref url="warpetts.md" %}
[warpetts.md](warpetts.md)
{% endcontent-ref %}

## Die ersten Stunden

* **Quests öffnen.** Mit `/quest` siehst du deine ersten Aufgaben. Sie sind die verlässlichste Mana-Quelle.
* **Unter die Insel schauen.** Neue Hauptinseln haben eine Höhle mit Eingang von oben – dort liegen die meisten Erze.
* **Brücken bauen.** Um deine Insel herum entstehen beim Erkunden neue Inseln. Je weiter du gehst, desto mehr gibt es zu entdecken.
* **Kanten sichern.** Der Sturz in die Leere ist im Skyblock der häufigste Grund für verlorene Sachen.
* **Freunde einladen.** Mit Mitgliedern kommst du schneller voran.
* **Erstes Biom aussuchen.** Du startest mit 1000 Mana – ein neues Biom im Skilltree kostet ab 100 Mana.

{% hint style="info" %}
Mana gibt es nur im Überlebensmodus und nicht für Blöcke, die du selbst platziert hast. Mehr dazu unter [Mana & Ruby](eco.md).
{% endhint %}

## Später wiederkommen

Beim nächsten Einloggen landest du direkt wieder auf deiner Insel, wenn du dort zuletzt warst. Sonst kommst du in die Lobby und betrittst deine Insel über `/sky` → **Insel betreten**.
