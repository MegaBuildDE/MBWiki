# Progression & Upgrades

Der Leitgedanke hinter dem Relaunch: **Jeder Ausbau, jedes Upgrade und jeder Schritt nach vorne soll sich spürbar lohnen und dich weiter pushen.**

Statt eines Fortschritts, der nach ein paar Stunden ausläuft, ist die Progression auf Langzeitspiel ausgelegt.

## Die drei Bausteine

{% columns %}
{% column %}
### Inselupgrades

Ausbaustufen für deine Insel, die Platz, Kapazität und Möglichkeiten erhöhen.
{% endcolumn %}

{% column %}
### Freischaltungen

Funktionen und Inhalte, die du dir erarbeitest – nicht solche, die von Anfang an offen liegen.
{% endcolumn %}
{% endcolumns %}

{% columns %}
{% column %}
### Langzeitziele

Ziele, die bewusst auf viele Stunden ausgelegt sind, statt nach einem Abend abgehakt zu sein.
{% endcolumn %}

{% column %}
### Und wie das zusammenhängt

Handel, Upgrades und Freischaltungen greifen ineinander – Fortschritt in einem Bereich öffnet Möglichkeiten in den anderen.
{% endcolumn %}
{% endcolumns %}

## Eigene Generatoren

Ein zentrales Element der Progression sind **eigene Generatoren** statt Standard-Abläufen. Sie bestimmen, welche Ressourcen dir zur Verfügung stehen – und damit, wie schnell du dich weiterentwickeln kannst.

Damit wird der Generator selbst zu einem Progressionsziel: Je weiter du kommst, desto besser wird das, was er produziert.

## Der Kreislauf

{% stepper %}
{% step %}
#### Produzieren

Generatoren und Farmen liefern dir Ressourcen.
{% endstep %}

{% step %}
#### Verwerten

Über Handel und die Server-Wirtschaft wird daraus Wert.
{% endstep %}

{% step %}
#### Freischalten

Mit diesem Wert schaltest du Upgrades und neue Funktionen frei.
{% endstep %}

{% step %}
#### Skalieren

Die Freischaltungen verbessern wiederum deine Produktion – und der Kreislauf beginnt auf einem höheren Level von vorn.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Genau dieses Ineinandergreifen ist gemeint, wenn von „Fortschritt, der sich gut anfühlt" die Rede ist: Du sollst ständig das Gefühl haben, wirklich etwas aufzubauen.
{% endhint %}
