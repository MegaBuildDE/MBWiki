# Wirtschaft & Handel

Spieler, Handel und Community sollen sich auf MegaBuild.de **lebendig anfühlen** und durch servereigene Systeme mehr Tiefe bekommen als bei typischen Standardlösungen.

## Die Rolle der Wirtschaft

Die Wirtschaft ist das Bindeglied zwischen dem, was du produzierst, und dem, was du freischaltest:

{% stepper %}
{% step %}
#### Du produzierst

Farmen und Generatoren liefern Ressourcen.

{% content-ref url="farming.md" %}
[farming.md](farming.md)
{% endcontent-ref %}
{% endstep %}

{% step %}
#### Du handelst

Über Handel und serverweite Wirtschaft wird aus Ressourcen Wert – im Austausch mit anderen Spielern oder über servereigene Systeme.
{% endstep %}

{% step %}
#### Du baust aus

Mit diesem Wert finanzierst du Inselupgrades und Freischaltungen.

{% content-ref url="progression.md" %}
[progression.md](progression.md)
{% endcontent-ref %}
{% endstep %}
{% endstepper %}

## Bestätigte Eckpunkte

* **Handel und serverweite Wirtschaft** als eigenes System
* **Vorteile, die sinnvoll in das Hauptspiel integriert sind** – also keine Abkürzungen, die den Fortschritt entwerten
* Wirtschaft und Community werden bewusst zusammen gedacht

{% content-ref url="community.md" %}
[community.md](community.md)
{% endcontent-ref %}

## Ränge und Shop

Ränge sind über den [MegaBuild.de-Shop](https://shop.megabuild.de/) erhältlich. Welche Vorteile sie im Skyblock konkret bringen, wird zum Start bekannt gegeben.

{% content-ref url="../ag/rang.md" %}
[rang.md](../ag/rang.md)
{% endcontent-ref %}

{% hint style="info" %}
**Wichtig zum Verständnis:** Käufe im Shop unterstützen den Server und laufen über Echtgeld. Der Anspruch laut Ankündigung ist, Vorteile so zu integrieren, dass sie das Hauptspiel ergänzen statt es zu ersetzen.
{% endhint %}

## Was noch offen ist

{% hint style="warning" %}
Die konkreten Wirtschaftssysteme sind **noch nicht öffentlich angekündigt**. Dazu gehören unter anderem:

* Währung und Startguthaben
* Spielershops und Handelsplätze
* Auktionshaus oder Markt
* Serverweite Preise und Ankaufsysteme
* Befehle rund um Geld und Handel

Sobald die Systeme final sind, findest du die echten Werte hier. Ankündigungen laufen über den [Discord](https://megabuild.de/dc/).
{% endhint %}
