# Mana & Ruby

Auf MegaBuild.de gibt es zwei Währungen. Beide gelten auf allen Servern und werden unten rechts über deiner Hungerleiste angezeigt.

| | Mana | Ruby |
| --- | --- | --- |
| **Wofür** | Biome im Skilltree, Quests überspringen | Handel zwischen Spielern |
| **Startguthaben** | 1000 | 0 |
| **Verschicken** | Nicht möglich | Mit `/pay` |

## Mana verdienen

### Durch Aktionen

Viele Tätigkeiten geben mit einer gewissen Chance Mana:

| Aktion | Chance | Mana |
| ------ | -----: | ---: |
| Erz abbauen | 8 % | 1–2 |
| Diamant-, Smaragd- oder Golderz | 35 % | 2–4 |
| Monster besiegen | 15 % | 1–2 |
| Angeln | 10 % | 1–3 |
| Mit Dorfbewohnern handeln | 12 % | 1–2 |
| Tier zähmen | 60 % | 4–8 |
| Tiere züchten | 10 % | 1–2 |
| Schafe scheren | 12 % | 1 |
| Ernten | 4 % | 1 |
| Verzaubern | 35 % | 2–5 |
| Alle 5 Level aufsteigen | 50 % | 1–3 |
| Überfall abwehren | 100 % | 20–40 |
| Fortschritt (Advancement) erreichen | 100 % | 3–8 |
| Werkzeug verschleißen (ab 200 Haltbarkeit) | 25 % | 2–4 |
| Items aus dem Ofen nehmen | 5 % | 1 |

{% hint style="info" %}
**Tageslimit: 150 Mana aus Aktionen.** Quests und Mana-Erz zählen nicht dazu. Das Limit setzt sich jeden Tag um **04:00 Uhr** zurück.
{% endhint %}

Fortschritte geben nur beim ersten Mal Mana – egal auf welcher Insel.

### Durch Mana-Erz

Mana-Erz sieht aus wie ein leuchtendes, magentafarbenes Tiefenschiefer-Lapiserz. Baust du es mit einer **Spitzhacke** ab, bekommst du **6–12 Mana** statt Lapis. **Glück** erhöht das um 25 % pro Stufe.

Für Mana-Erz gilt ein eigenes Tageslimit von **200 Mana**.

Quests geben die größten Mana-Belohnungen und haben kein Tageslimit.

### Was kein Mana gibt

* Alles außerhalb des **Überlebensmodus**
* Blöcke, die du **selbst platziert** hast
* Erz, das du **ohne Spitzhacke** abbaust
* Monster aus **Spawnern**, Spawn-Eiern oder Befehlen
* **AFK-Angeln** oder Angeln außerhalb von offenem Wasser

## Befehle

| Befehl | Was er macht |
| ------ | ------------ |
| `/bal [Spieler]` | Kontostand anzeigen |
| `/baltop [mana\|ruby] [Seite]` | Die reichsten Spieler, 10 pro Seite |
| `/pay <Spieler> <Menge>` | Ruby verschicken |

### Ruby verschicken

* Es gibt **keine Gebühr** und keine Bestätigungsabfrage – prüfe den Namen vorher genau.
* Du kannst auch Spielern schicken, die gerade offline sind.
* Beträge dürfen Tausenderpunkte haben: `1000`, `1.000` und `1,000` funktionieren. Kommazahlen gehen nicht.
