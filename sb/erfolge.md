# Erfolge

Neben den normalen Minecraft-Fortschritten gibt es einen eigenen Tab **„MegaBuild Sky“** mit **22 Erfolgen** rund um Luftschiff, Mana, Mobplates, Skilltree und Quests.

* Jeder Erfolg zählt **einmal im ganzen Netzwerk**. Hast du ihn auf einer Insel bekommen, hast du ihn auf allen anderen auch.
* Beim ersten Mal gibt es **3–8 Mana** – nur im Überlebensmodus, und es zählt zum Tageslimit für [Aktionen](eco.md#durch-aktionen).

## So siehst du sie

| | Java | Bedrock |
| --- | --- | --- |
| **Liste** | Fortschrittsmenü (Taste **L**), Tab *MegaBuild Sky* | Befehl `/geyser advancements` |
| **Beim Erreichen** | Meldung oben rechts und im Chat | Meldung oben und im Chat |
| **Sprache** | Sprache deines Clients | immer Deutsch |

## Alle Erfolge

### Ankommen

| Erfolg | Wofür |
| ------ | ----- |
| **Gelandet** | Den Vorspann auf dem Luftschiff abschließen |
| **Durchs Blumennetz** | Mit einem [Warpett](warpetts.md) reisen |

### Mana

| Erfolg | Wofür |
| ------ | ----- |
| **Magisches Gestein** | [Mana-Erz](eco.md#mana-erz) abbauen |
| **Aufs Konto** | Mana-Kugeln beim Ofen-Golem einzahlen – *noch nicht erreichbar, den Ofen-Golem gibt es noch nicht* |
| **Verdichtet** | Eine Mana-Ladung craften |
| **Magische Frucht** | Einen Mana-Apfel craften |

### Mobplates

| Erfolg | Wofür |
| ------ | ----- |
| **Erster Fang** | Einen Mob mit einer [Mobplate](mobplates.md) fangen – ein Dorfbewohner oder Warpett ohne Kampf zählt auch |
| **Neu eingezogen** | Einen gefangenen Mob mit seiner Mobplate platzieren – auch mit der Plate von jemand anderem |

### Skilltree

| Erfolg | Wofür |
| ------ | ----- |
| **Neues Land** | Dein erstes Biom im [Skilltree](skilltree.md) kaufen |
| **Ganzer Pfad** | Alle Biome eines Pfads besitzen |
| **Weltenbauer** | Alle freischaltbaren Biome besitzen |

Dazu kommt ein Erfolg **für jeden ganzen Kristall-Pfad**:

| Erfolg | Pfad |
| ------ | ---- |
| **Weites Land** | Ebenen |
| **Waldläufer** | Wälder |
| **Ewiger Frost** | Schnee & Eis |
| **Gipfelstürmer** | Gebirge |
| **Sumpfkenner** | Sumpf & Selten |
| **Herz des Dschungels** | Dschungel |
| **Wüstenwind** | Wüste & Steppe |
| *versteckt* | Gewässer – erscheint, sobald der Kristall freigeschaltet wird |

### Quests

| Erfolg | Wofür |
| ------ | ----- |
| **Tagwerk** | Deine erste Tagesquest erledigen |
| **Wochenwerk** | Deine erste Wochenquest erledigen |
| **Questmeister** | 50 Quests erledigen |

### Clan

Dazu kommen **8 Erfolge** für [Clans](clans.md):

| Erfolg | Wofür |
| ------ | ----- |
| **Gemeinsam stark** | Mitglied eines Clans werden |
| **Bronze** | Deine erste Bronze-Belohnung aus dem Wochenauftrag |
| **Silber** | Deine erste Silber-Belohnung aus dem Wochenauftrag |
| **Gold** | Deine erste Gold-Belohnung aus dem Wochenauftrag |
| **Gastfreundlich** | Ein Clanmitglied auf deiner Insel empfangen |
| **Helfende Hand** | Zum ersten Mal für deine Hilfe bei einem Hilferuf belohnt werden |
| *versteckt* | Zwei Erfolge rund um die Clan-Insel – erscheinen, sobald sie freigeschaltet ist |

Verdienst du einen Clan-Erfolg, während du offline bist, bekommst du ihn samt Mana beim nächsten Betreten einer Insel.

## Gut zu wissen

* **Gelandet** bekommt der Besitzer der Insel – nur er erlebt den Vorspann.
* Skilltree-Erfolge bekommt, wer das Biom kauft. Der Besitzer bekommt sie beim nächsten Betreten seiner Insel.
* Du kannst einen Erfolg auch vor dem davor erreichen, wie bei Minecraft.
