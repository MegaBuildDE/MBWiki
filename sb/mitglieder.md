# Mitglieder & Rechte

Du kannst bis zu **25 Mitglieder** auf deine Insel einladen und für jedes einzeln festlegen, was es darf.

## Mitglied einladen

{% stepper %}
{% step %}
#### Menü öffnen

**In der Lobby:** `/sky` → **Mitglieder** → **Mitglied hinzufügen**

**Auf der Insel:** `/sky friends` → **Mitglied hinzufügen**
{% endstep %}

{% step %}
#### Spieler auswählen

Zuerst siehst du deine Freundesliste. Über die Suche findest du alle Spieler im Netzwerk, auch offline – gib dafür mindestens **3 Zeichen** des Namens ein.
{% endstep %}

{% step %}
#### Bestätigen

Klicke auf **Einladen**. Der Spieler bekommt eine Nachricht und eine Post und darf deine Insel ab sofort betreten.
{% endstep %}
{% endstepper %}

Einladen dürfen der Besitzer und Mitglieder mit dem Recht **Freunde verwalten**.

## Die Rechte

| Recht | Was es erlaubt |
| ----- | -------------- |
| **Beitreten** | Die Insel betreten |
| **Statistiken** | Die Statistiken der Insel ansehen |
| **Einstellungen** | Einstellungen ändern und **Biome im Skilltree kaufen** |
| **Freunde verwalten** | Weitere Mitglieder einladen |
| **Server löschen** | Gefährlich – in keiner Rolle enthalten |

Als Besitzer hast du immer alle Rechte.

## Rollen

Damit du nicht jedes Recht einzeln setzen musst, gibt es drei Rollen:

| Rolle | Beitreten | Statistiken | Einstellungen | Freunde verwalten |
| ----- | :-------: | :---------: | :-----------: | :---------------: |
| **Besucher** | ✅ | – | – | – |
| **Vertraut** | ✅ | ✅ | ✅ | – |
| **Admin** | ✅ | ✅ | ✅ | ✅ |

Stellst du Rechte einzeln um, zeigt das Menü die Rolle als **Benutzerdefiniert** an.

## Mitglieder bearbeiten

In der Mitgliederliste siehst du die Köpfe deiner Mitglieder:

* **Linksklick** öffnet die Rechte. Mit **Rolle wechseln** gehst du Besucher → Vertraut → Admin durch, darunter schaltest du einzelne Rechte an und aus.
* **Rechtsklick** entzieht dem Spieler den Zugriff.

{% hint style="warning" %}
**Biome kauft, wer klickt.** Kauft ein Mitglied mit dem Recht Einstellungen ein Biom, wird das Mana **von seinem Konto** abgebucht – nicht von deinem.
{% endhint %}

## Inseln, auf denen du Mitglied bist

In der Lobby öffnest du mit `/sky` → **Geteilte Server** eine Liste aller Inseln, auf denen du Mitglied bist. Ein Klick bringt dich hin, auch wenn die Insel gerade nicht läuft.

Welche Rechte du auf einer Insel hast, siehst du dort unter `/sky` → **Deine Rechte**.
