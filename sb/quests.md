# Quests

Quests sind deine verlässlichste Mana-Quelle. Öffne sie mit `/quest` oder über `/sky` → **Quests**.

## Deine Quests

| Quest | Belohnung | Läuft bis |
| ----- | --------: | --------- |
| **Leicht** | 15–25 Mana | Du sie erledigst |
| **Mittel** | 30–50 Mana | Du sie erledigst |
| **Schwer** | 60–90 Mana | Du sie erledigst |
| **Woche** | 250–400 Mana | Montag, 04:00 Uhr |
| **Bonus** | 120–180 Mana | Montag, 04:00 Uhr |

* **Tagesquests** bleiben offen, bis du sie erledigst. Für eine erledigte Quest bekommst du um **04:00 Uhr** eine neue.
* **Die Wochenquest** läuft von Montag 04:00 bis Montag 04:00. Schaffst du sie nicht, verfällt sie.
* **Die Bonusquest** schaltest du frei, wenn du die Wochenquest innerhalb von **3 Tagen** erledigst – also bis Donnerstag, 04:00 Uhr.

## Überspringen

Passt dir eine Quest nicht, kannst du sie gegen eine andere Aufgabe gleicher Schwierigkeit tauschen.

| Quest | Kosten |
| ----- | -----: |
| Erster Skip pro Tag (nur Tagesquests) | kostenlos |
| Leicht | 20 Mana |
| Mittel | 35 Mana |
| Schwer | 60 Mana |
| Woche | 150 Mana |
| Bonus | 80 Mana |

## Im HUD anheften

Klicke im Questmenü auf eine Quest, um sie oben im HUD anzuheften. Dann siehst du ihren Fortschritt beim Spielen.

## Was für Aufgaben es gibt

Quests kommen aus elf Themen: **Kampf, Bergbau, Holzfäller, Farm, Angeln, Tiere, Handwerk, Erkundung, Magie, Bauen** und **Handel**.

Typische Aufgaben sind Monster besiegen, Blöcke abbauen, Bäume fällen, ernten, angeln, züchten, zähmen, scheren, schmelzen, herstellen, verzaubern, handeln, bauen, essen, eine Strecke laufen, Inseln oder Biome besuchen und Beute plündern.

Schwerere Quests haben manchmal eine **Zusatzbedingung**, zum Beispiel *mit TNT*, *nachts*, *bei Regen* oder *aus mindestens 15 Blöcken*. Dafür gibt es mehr Mana.

{% hint style="info" %}
**Quests passen zu deiner Insel.** Du bekommst nur Aufgaben, die mit deinen freigeschalteten Biomen machbar sind – zum Beispiel keinen Dorfhandel ohne Dorf-Biom.
{% endhint %}

## Was nicht zählt

* Blöcke, die du **selbst platziert** hast, zählen nicht für Abbau-Quests.
* **Stein aus Lava-Wasser-Generatoren** zählt nicht.
* Bei **Bau-Quests** zählt nur, was stehen bleibt – baust du Blöcke wieder ab, wird der Fortschritt abgezogen.
* Beim **Laufen** zählen höchstens 8 Blöcke pro Sekunde, und nach 30 Sekunden ohne Bewegung nichts mehr.
* Eine **Beute-Truhe** zählt nur für den Spieler, der sie zuerst öffnet.

## Serie

Im Questmenü siehst du deine **Serie**: an wie vielen Tagen hintereinander du mindestens eine Quest erledigt hast, dazu deinen Rekord.
