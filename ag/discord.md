# Discord

Der Discord ist neben dem Server die zentrale Anlaufstelle: Ankündigungen, Support, Feedback und Austausch mit anderen Spielern. Im Spiel bekommst du den Link mit `/discord` (auch `/dc`).

{% embed url="https://megabuild.de/dc/" %}

## Freischalten

Neu auf dem Discord siehst du zuerst nur wenige Kanäle.

{% stepper %}
{% step %}
#### Regeln lesen und bestätigen

Lies die Regeln und bestätige sie mit dem Knopf darunter.
{% endstep %}

{% step %}
#### Kurze Aufgabe lösen

Der Bot stellt dir eine kleine Aufgabe, damit klar ist, dass du kein Bot bist.
{% endstep %}

{% step %}
#### Fertig

Danach siehst du alle Kanäle. Willst du bei Neuigkeiten einen Ping bekommen, hol dir die **Info-Rolle** – mit `/info` oder per Knopf. `/remove` nimmt sie wieder weg.

Sprichst du Englisch? Hol dir per Knopf die **English-Rolle**. Jede Nachricht übersetzt du dir per Rechtsklick (am Handy lange drücken) → Apps → **Übersetzen** – das siehst nur du.
{% endstep %}
{% endstepper %}

## Minecraft-Account verbinden

Verbinde deinen Minecraft-Account mit Discord. Dann kommen Belohnungen aus dem Discord – etwa für Bug-Meldungen – automatisch auf dein Konto im Spiel.

{% stepper %}
{% step %}
#### Code im Spiel holen

Gib im Spiel `/connect` ein. Du bekommst einen **6-stelligen Code**, der 10 Minuten gilt.
{% endstep %}

{% step %}
#### Code im Discord eingeben

Im Discord `/connect code:DEINCODE` – oder im Kanal zum Verbinden auf **Code eingeben** klicken.
{% endstep %}
{% endstepper %}

| Was | Im Spiel | Im Discord |
| --- | -------- | ---------- |
| Verbindung ansehen | `/connect status` | `/connect` ohne Code |
| Verbindung lösen | `/connect trennen` | `/disconnect` |

{% hint style="info" %}
Das ist etwas anderes als das Verbinden von **Java- und Bedrock-Account** – das steht unter [Accounts verbinden](connect-account.md).
{% endhint %}

## Tickets

Für alles Persönliche öffnest du im Discord ein **Ticket** – per Knopf im passenden Kanal. Nur du und das Team sehen es.

| Ticket | Wofür |
| ------ | ----- |
| **Support** | Fragen, Probleme mit deinem Account, Meldungen von Regelverstößen |
| **Bug-Bounty** | Einen Fehler auf dem Server melden |
| **ClipCoin** | Ein Video, einen Stream oder einen Beitrag über MegaBuild.de einreichen |

### Bug-Bounty und ClipCoin

Für gemeldete Fehler und Inhalte über MegaBuild.de gibt es eine Belohnung. Das Team stuft beim Schließen des Tickets ein:

| Bug-Bounty | Belohnung |
| ---------- | --------- |
| **Schwerer Bug** – Dupe, Exploit, Datenverlust, Absturz | 600 Mana + 200 Ruby |
| **Bug** | 250 Mana + 75 Ruby |
| **Schönheitsfehler** | 50 Mana + 10 Ruby |

| ClipCoin | Belohnung |
| -------- | --------- |
| **Video oder Stream** | 500 Mana + 100 Ruby |
| **Beitrag oder Idee** | 150 Mana + 30 Ruby |

* Die Belohnung kommt **direkt auf dein Konto**, dazu eine Danke-Nachricht in deine [Post](nachrichten.md) im Spiel.
* Dafür muss dein Minecraft-Account [verbunden](#minecraft-account-verbinden) sein. Ist er es noch nicht, schreibt dir der Bot – sobald du verbindest, wird ausgezahlt.
* Ob und wie eine Meldung angerechnet wird, entscheidet das Team.

{% hint style="warning" %}
**Fehler ausnutzen statt melden** verstößt gegen die Regeln. Melde Bugs, besonders Dupes und Exploits, nur über ein Ticket – nicht öffentlich.
{% endhint %}

## Private Talks

Betrittst du den Sprachkanal zum Erstellen, bekommst du deinen **eigenen Sprachkanal**. Darin steuerst du ihn mit:

| Befehl | Was er macht |
| ------ | ------------ |
| `/lock` · `/unlock` | Kanal schließen oder wieder öffnen |
| `/limit` | Höchstzahl an Leuten festlegen |
| `/rename` | Kanal umbenennen |
| `/adduser` | Jemanden in den geschlossenen Kanal holen |

## Level

Wer im Discord schreibt und in Sprachkanälen ist, sammelt Erfahrung – es gibt ein **Chat-Level** und ein **Voice-Level**. Mit bestimmten Leveln bekommst du Rollen.

* `/rank` zeigt deine Rangkarte – oder die eines anderen.
* `/top10` zeigt beide Bestenlisten.

## Alle Bot-Befehle

| Befehl | Was er macht |
| ------ | ------------ |
| `/help` | Übersicht |
| `/ip` | Server-Adresse |
| `/vote` | Vote-Link |
| `/wiki` | Link zu diesem Wiki |
| `/invite` | Einladungslink zum Discord |
| `/socialmedia` | Unsere Kanäle |
| `/info` · `/remove` | Info-Rolle holen oder abgeben |
| `/connect` · `/disconnect` | Minecraft-Account verbinden oder lösen |
| `/rank` · `/top10` | Rangkarte und Bestenlisten |

Jeder Befehl geht auch mit `!` statt `/`, zum Beispiel `!ip`.
