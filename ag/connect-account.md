# Java und Bedrock Account verbinden

MegaBuild.de ist crossplay-fähig. Wenn du sowohl mit einem **Java**- als auch mit einem **Bedrock**-Account (Handy, Tablet, Windows, Konsole) spielst, kannst du beide zu einem gemeinsamen Spielstand verbinden.

{% hint style="info" %}
Wenn du **nur** mit Java **oder nur** mit Bedrock spielst, brauchst du diese Seite nicht.
{% endhint %}

{% hint style="danger" %}
**Lies das vor dem Verbinden.**

Beim Verbinden wird dein Bedrock-Account mit dem Spielstand deines **Java**-Accounts zusammengeführt. Ein bereits vorhandener **Fortschritt auf dem Bedrock-Account geht dabei verloren.**

Verbinde die Accounts also am besten, **bevor** du auf dem Bedrock-Account ernsthaft anfängst zu spielen.
{% endhint %}

## Anleitung

{% stepper %}
{% step %}
#### Mit beiden Accounts verbinden

Gehe mit **beiden** Accounts auf den Server:

```
megabuild.de
```

Bedrock nutzt zusätzlich den Port `19132`.

{% content-ref url="join.md" %}
[join.md](join.md)
{% endcontent-ref %}
{% endstep %}

{% step %}
#### Befehl auf dem Java-Account

Gib diesen Befehl im Chat deines **Java**-Accounts ein:

```
/linkaccount <Name-des-BE-Accounts>
```
{% endstep %}

{% step %}
#### Code auf dem Bedrock-Account eingeben

Du erhältst daraufhin im Chat deines Java-Accounts einen Code. Diesen gibst du auf deinem **Bedrock**-Account ein:

```
/linkaccount <Name-des-Java-Accounts> <Code>
```
{% endstep %}

{% step %}
#### Neu verbinden

Hat alles geklappt, wirst du gekickt und zum erneuten Beitreten aufgefordert. Ab dem nächsten Login teilen sich beide Accounts denselben Spielstand.
{% endstep %}
{% endstepper %}

## Wichtige Hinweise

{% hint style="warning" %}
**Geld auf andere Accounts zu übertragen, um Regeln zu umgehen, ist nicht erlaubt** und wird als Regelverstoß behandelt. Die vollständigen Regeln findest du unter [megabuild.de/rules](https://megabuild.de/rules/).
{% endhint %}

<details>

<summary>Der Befehl funktioniert nicht</summary>

* Prüfe die Schreibweise beider Accountnamen – Groß- und Kleinschreibung zählt.
* Stelle sicher, dass **beide** Accounts gleichzeitig online sind.
* Der Code ist in der Regel nur kurze Zeit gültig. Ist er abgelaufen, starte den Vorgang neu.

</details>

<details>

<summary>Kann ich die Verbindung wieder aufheben?</summary>

Wende dich dafür an den [Ticket-Support](https://megabuild.de/ticket/). Beachte, dass ein Trennen den zusammengeführten Spielstand nicht automatisch wiederherstellt.

</details>

<details>

<summary>Ich habe den falschen Account verbunden</summary>

Melde dich so schnell wie möglich beim [Ticket-Support](https://megabuild.de/ticket/) – je früher, desto besser stehen die Chancen, das sauber zu korrigieren.

</details>
