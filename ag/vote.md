# Voten

Voten ist die einfachste Art, MegaBuild.de zu unterstützen – es kostet nichts und dauert weniger als eine Minute.

## Wie voten?

{% stepper %}
{% step %}
#### Vote-Seite öffnen

Gehe auf [megabuild.de/vote](https://megabuild.de/vote/) – oder gib im Spiel `/vote` ein, dann bekommst du den Link in den Chat.
{% endstep %}

{% step %}
#### Namen eintragen

Gib deinen Minecraft-Namen ein. Groß- und Kleinschreibung ist egal – aber achte auf Tippfehler, sonst kommt die Belohnung bei jemand anderem an. Bedrock-Spieler geben ihren Namen so ein, wie er auf dem Server angezeigt wird.
{% endstep %}

{% step %}
#### Auf den Vote-Listen abstimmen

Bestätige deinen Vote auf den verlinkten Serverlisten. Meist ist pro Liste **ein Vote alle 24 Stunden** möglich.
{% endstep %}
{% endstepper %}

{% embed url="https://megabuild.de/vote/" %}

## Was bringt das?

### Deine Belohnung

| Pro Vote | |
| -------- | -: |
| Mana | **20** |
| Ruby | **1** |

* Belohnt wird **jeder Vote** – ein Tageslimit gibt es nicht.
* Vote-Mana zählt **nicht** zum Tageslimit für Aktionen.
* **Warst du offline?** Dann bekommst du die Belohnung trotzdem – mit einer Nachricht von *MegaBuild.de* in deiner [Post](nachrichten.md).
* **Noch nie auf dem Server gewesen?** Votes der letzten 7 Tage vor deinem ersten Join werden beim ersten Betreten nachgetragen.

Neben den 1.000 Ruby, mit denen jedes Konto startet, sind Votes der regelmäßige Weg zu mehr **Ruby** – der Währung für den Handel zwischen Spielern.

### Im Spiel

`/vote` zeigt dir den Link, deine Belohnung, wie oft du **heute** schon gevotet hast und deine Votes im Monat und insgesamt.

### Für den Server

Jeder Vote schiebt MegaBuild.de in den Serverlisten nach oben und hilft dabei, neue Spieler zu erreichen.

## Häufige Fragen

<details>

<summary>Ich habe gevotet, aber keine Belohnung bekommen</summary>

Die häufigsten Ursachen:

1. **Tippfehler im Namen.** Dann ging die Belohnung an einen anderen Namen.
2. **Du warst offline.** Schau in deine Post mit `/mail`.

Hilft alles nichts? Melde dich im [Support](support.md).

</details>

<details>

<summary>Kann ich mit mehreren Accounts voten?</summary>

Nein. Das Voten mit mehreren Accounts oder das Umgehen der Limits der Serverlisten verstößt gegen die [Serverregeln](https://megabuild.de/rules/).

</details>

<details>

<summary>Zählt mein Vote auch, wenn der Server in Wartung ist?</summary>

Der Vote selbst wird auf den Serverlisten registriert. Belohnungen können aber erst ausgegeben werden, wenn der Server wieder erreichbar ist.

</details>
