# Befehle

Die meisten Funktionen erreichst du über Menüs. Diese Befehle bringen dich direkt hin. In eckigen Klammern `[ ]` steht, was du weglassen kannst, in spitzen `< >`, was du einsetzen musst.

## Skyblock

| Befehl | Was er macht |
| ------ | ------------ |
| `/sky` | **In der Lobby:** Insel erstellen, betreten, verwalten. **Auf einer Insel:** das Inselmenü. Auch `/skyblock` |
| `/quest` | Deine Quests. Auch `/quests`, `/sky quests`, `/sky q` |
| `/sky skills` | Skilltree – neue Biome freischalten |
| `/sky friends` | Mitglieder deiner Insel |
| `/sky island` | Infos zu deiner Insel |
| `/sky stats` | Deine Statistiken |
| `/sky global` | Statistiken des ganzen Servers |
| `/sky visit <Spieler>` | Auf die Insel eines Spielers – mit Zugang als Mitspieler, sonst als [Zuschauer](../sb/reisen.md), wenn die Insel es erlaubt. Auch aus der Lobby |
| `/sky visit` | Das Reisemenü: offene Inseln und die Inseln deiner Freunde |

Die Befehle mit `/sky …` und `/quest` gibt es nur **auf den Inseln**, außer `/sky visit <Spieler>`. In der Lobby öffnet `/sky` sonst immer das Skyblock-Menü. `/sky stats` und `/sky global` brauchen auf fremden Inseln das Recht **Statistik**.

## Clans

| Befehl | Was er macht |
| ------ | ------------ |
| `/clan` | Dein Clan – oder Clan finden und gründen. Auch `/clans` |
| `/c <Text>` | Eine Zeile in den Clan-Chat. `/c` allein schaltet den Clan-Chat an und aus. Auch `#` vor der Nachricht |
| `/clan visit <Spieler>` | Auf die Insel eines Clanmitglieds |
| `/clan home` | Zurück auf deine eigene Insel |
| `/clan meet` | Deinen Clan zu dir auf die Insel einladen |
| `/clan help` | Alle Clan-Befehle |

Alle Befehle stehen unter [Clans](../sb/clans.md#alle-befehle).

## KI-Bewohner

| Befehl | Was er macht |
| ------ | ------------ |
| `/bewohner` | Alle Bewohner, die du kennst – mit Biom, Koordinaten und Vertrauen. Auch `/residents` |
| `/bewohner liste` | Dasselbe als Liste im Chat |
| `/ki` | Einstellen, was Bewohner bei dir dürfen |
| `/ki aus` · `/ki an` | Ansprechen, Szenen und Chat der Bewohner aus- oder einschalten |
| `/ki melden` | Deine Eingaben an Bewohner der letzten 30 Minuten dem Team zur Prüfung melden |
| `/auftraege` | Aufträge, Tauschgesuche und Lieferungen. Auch `/orders` |

Nur auf den Inseln. Mehr dazu unter [KI-Bewohner](../sb/bewohner.md).

## Mana & Ruby

| Befehl | Was er macht |
| ------ | ------------ |
| `/bal [Spieler]` | Kontostand – deiner oder der eines anderen. Auch `/balance`, `/money` |
| `/baltop [mana\|ruby] [Seite]` | Reichste Spieler. Auch `/balancetop` |
| `/pay <Spieler> <Menge>` | Ruby an einen Spieler senden |

Mana lässt sich nicht verschicken – nur Ruby.

## ChestShops

| Befehl | Was er macht |
| ------ | ------------ |
| `/shop` | Shop-Menü: suchen, Märkte, deine Shops. Auch `/shops`, `/sky shop` |
| `/shop search [Begriff]` | Angebote aller Inseln suchen |
| `/shop hand` | Wer handelt das Item in deiner Haupthand? |
| `/shop markets` | Offene Märkte aller Inseln |
| `/shop mine` | Deine Shops mit Vorrat und Platz |
| `/shop areas` | Shop-Bereiche dieser Insel |
| `/shop home` | Zurück auf deine eigene Insel |

Nur auf den Inseln. Alle Befehle stehen unter [ChestShops](../sb/chestshop.md#befehle).

## Rang-Befehle

| Befehl | Rang | Was er macht |
| ------ | ---- | ------------ |
| `/craft` | Gold | Eine Werkbank ohne Block. Auch `/workbench`, `/wb` |
| `/stonecutter` · `/loom` · `/cartography` | Platin | Steinsäge, Webstuhl oder Kartentisch ohne Block |
| `/trash` | Gold | Der Mülleimer – weg ist nur, was du bestätigst |
| `/trash undo` | Gold | Holt das zuletzt Weggeworfene 5 Minuten lang zurück |
| `/ec` | Gold | Deine [Enderkiste](rang.md#enderkiste) von überall. Auch `/enderchest` |
| `/ptime morning` · `noon` · `evening` · `night` | Platin | Deine eigene Uhrzeit – nur du siehst sie |
| `/ptime <Uhrzeit>` | Titan | Jede Uhrzeit, zum Beispiel `/ptime 21:30` |
| `/ptime freeze` | Titan | Deine Uhrzeit anhalten oder weiterlaufen lassen |
| `/ptime reset` | Platin | Wieder die Uhrzeit der Insel |
| `/hat` | Gold | Das Item in deiner Hand als Hut – nur zum Anschauen. `/hat off` nimmt ihn ab |
| `/sit` · `/lay` · `/crawl` | Gold | Sitzen, liegen, kriechen. Noch einmal tippen oder schleichen zum Aufstehen |
| `/rename [Name]` | Gold | Das Item in deiner Hand umbenennen – mit Platin farbig, mit Titan auch RGB und Verlauf. `/rename clear` nimmt den Namen ab |
| `/head <Spieler>` | Gold | Den Kopf eines Spielers holen, an dich gebunden. Gold 1 im Monat, Platin 1 in der Woche, Titan 1 am Tag |
| `/nick <Name>` | Platin | Ein anderer Name in Chat und Tablist, mit `~` davor. `/nick clear` nimmt ihn weg |
| `/status <Text>` | Platin | Ein Text hinter deinem Namen in der Tablist. `/status clear` nimmt ihn weg |

`/nick` und `/status` gehen im ganzen Netzwerk. Alle anderen Rang-Befehle gehen auf allen Sky-Inseln, auch als Besucher – nicht in den 10 Sekunden nach einem Treffer und nicht als Kunde auf einem fremden Markt. Ein höherer Rang hat alles vom Rang darunter. Mehr dazu unter [Ränge](rang.md#vorteile-im-ganzen-netzwerk).

## Freunde & Nachrichten

| Befehl | Was er macht |
| ------ | ------------ |
| `/friend` | Deine Freundesliste. Auch `/friends`, `/friend list` |
| `/friend <Spieler>` | Freundschaftsanfrage senden – oder seine annehmen |
| `/friend add` | Spieler, die du fragen kannst |
| `/friend requests` | Offene Anfragen |
| `/g <Text>` | Eine Zeile in den [Globalchat](nachrichten.md#globalchat) – an alle im Netzwerk, auch beim Forestling. Auf einer Bewohnerinsel geht es nicht. Eine normale Chatzeile geht ebenfalls ins Netzwerk; mit `!` vorn bleibt sie auf deinem Server |
| `/msg <Spieler> <Text>` | Private Nachricht – ist der Spieler nicht da, landet sie in seiner Post. Auch `/tell`, `/w` |
| `/r <Text>` | Auf die letzte private Nachricht antworten. Auch `/reply` |
| `/mail` | Dein Postfach. Auch `/post` |
| `/mail <Spieler> <Text>` | Schnell eine Nachricht in die Post schicken |

## Netzwerk

| Befehl | Was er macht |
| ------ | ------------ |
| `/hub` | Zurück in die Lobby. Auch `/lobby` |
| `/ot [Spieler]` | Spielzeit und erster Join. Auch `/onlinetime`, `/playertime`, `/otime`, `/pt` – aber nicht `/ptime`, das ist der Rang-Befehl für die [eigene Uhrzeit](rang.md#eigene-uhrzeit) |
| `/vote` | Vote-Link, deine Belohnung und wie oft du heute schon gevotet hast. Auch `/votes` |
| `/connect` | Minecraft- und Discord-Account verbinden. `/connect status` zeigt den Stand, `/connect trennen` löst die Verbindung |
| `/linkaccount` | Java- und Bedrock-Account verbinden |
| `/discord` | Link zum Discord. Auch `/dc` |
| `/wiki` | Link zu diesem Wiki. Auch `/help` |

{% hint style="info" %}
**Auf dem Intro-Server** – während des Vorspanns mit Mala – funktionieren nur die Netzwerk-Befehle.
{% endhint %}
