# Befehle

Die meisten Funktionen erreichst du über Menüs. Diese Befehle bringen dich direkt hin. In eckigen Klammern `[ ]` steht, was du weglassen kannst, in spitzen `< >`, was du einsetzen musst.

## Skyblock

| Befehl | Was er macht |
| ------ | ------------ |
| `/sky` | **In der Lobby:** Insel erstellen, betreten, verwalten. **Auf einer Insel:** das Inselmenü. Auch `/skyblock` |
| `/quest` | Deine Quests. Auch `/quests`, `/sky quests`, `/sky q` |
| `/sky skills` | Skilltree – neue Biome freischalten |
| `/sky friends` | Mitglieder deiner Insel |
| `/sky island` | Infos zu deiner Insel |
| `/sky stats` | Deine Statistiken |
| `/sky global` | Statistiken des ganzen Servers |

Die Befehle mit `/sky …` und `/quest` gibt es nur **auf den Inseln**. In der Lobby öffnet `/sky` immer das Skyblock-Menü. `/sky stats` und `/sky global` brauchen auf fremden Inseln das Recht **Statistiken**.

## KI-Bewohner

| Befehl | Was er macht |
| ------ | ------------ |
| `/bewohner` | Alle Bewohner, die du kennst – mit Biom, Koordinaten und Vertrauen. Auch `/residents` |
| `/bewohner liste` | Dasselbe als Liste im Chat |
| `/ki` | Einstellen, was Bewohner bei dir dürfen |
| `/ki aus` · `/ki an` | Ansprechen, Szenen und Chat der Bewohner aus- oder einschalten |
| `/ki melden` | Deine Eingaben an Bewohner der letzten 30 Minuten dem Team zur Prüfung melden |
| `/auftraege` | Aufträge, Tauschgesuche und Lieferungen. Auch `/orders` |

Nur auf den Inseln. Mehr dazu unter [KI-Bewohner](../sb/bewohner.md).

## Mana & Ruby

| Befehl | Was er macht |
| ------ | ------------ |
| `/bal [Spieler]` | Kontostand – deiner oder der eines anderen. Auch `/balance`, `/money` |
| `/baltop [mana\|ruby] [Seite]` | Reichste Spieler. Auch `/balancetop` |
| `/pay <Spieler> <Menge>` | Ruby an einen Spieler senden |

Mana lässt sich nicht verschicken – nur Ruby.

## Freunde & Nachrichten

| Befehl | Was er macht |
| ------ | ------------ |
| `/friend` | Deine Freundesliste. Auch `/friends`, `/friend list` |
| `/friend <Spieler>` | Freundschaftsanfrage senden – oder seine annehmen |
| `/friend add` | Spieler, die du fragen kannst |
| `/friend requests` | Offene Anfragen |
| `/msg <Spieler> <Text>` | Private Nachricht – ist der Spieler nicht da, landet sie in seiner Post. Auch `/tell`, `/w` |
| `/r <Text>` | Auf die letzte private Nachricht antworten. Auch `/reply` |
| `/mail` | Dein Postfach. Auch `/post` |
| `/mail <Spieler> <Text>` | Schnell eine Nachricht in die Post schicken |

## Netzwerk

| Befehl | Was er macht |
| ------ | ------------ |
| `/hub` | Zurück in die Lobby. Auch `/lobby` |
| `/ot [Spieler]` | Spielzeit und erster Join. Auch `/onlinetime`, `/pt` |
| `/vote` | Vote-Link, deine Belohnung und wie oft du heute schon gevotet hast. Auch `/votes` |
| `/connect` | Minecraft- und Discord-Account verbinden. `/connect status` zeigt den Stand, `/connect trennen` löst die Verbindung |
| `/linkaccount` | Java- und Bedrock-Account verbinden |
| `/discord` | Link zum Discord. Auch `/dc` |
| `/wiki` | Link zu diesem Wiki. Auch `/help` |

{% hint style="info" %}
**Auf dem Intro-Server** – während des Vorspanns mit Mala – funktionieren nur die Netzwerk-Befehle.
{% endhint %}
