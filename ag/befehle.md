# Befehle

Die meisten Funktionen erreichst du über Menüs. Diese Befehle bringen dich direkt hin.

## Skyblock

| Befehl | Was er macht |
| ------ | ------------ |
| `/sky` | **In der Lobby:** Insel erstellen, betreten, verwalten. **Auf einer Insel:** das Inselmenü |
| `/quest` | Deine Quests |
| `/sky skills` | Skilltree – neue Biome freischalten |
| `/sky friends` | Mitglieder deiner Insel |
| `/sky island` | Infos zu deiner Insel |
| `/sky stats` | Deine Statistiken auf dieser Insel |
| `/sky global` | Statistiken des ganzen Servers |

`/sky stats` und `/sky global` brauchen auf fremden Inseln das Recht **Statistiken**.

## Mana & Ruby

| Befehl | Was er macht |
| ------ | ------------ |
| `/bal [Spieler]` | Kontostand – deiner oder der eines anderen Spielers |
| `/baltop [mana\|ruby] [Seite]` | Reichste Spieler |
| `/pay <Spieler> <Menge>` | Ruby an einen Spieler senden |

Mana lässt sich nicht verschicken – nur Ruby.

## Freunde & Nachrichten

| Befehl | Was er macht |
| ------ | ------------ |
| `/friend` | Deine Freundesliste |
| `/friend <Spieler>` | Freundschaftsanfrage senden oder annehmen |
| `/friend requests` | Offene Anfragen |
| `/msg <Spieler> <Text>` | Private Nachricht – ist der Spieler nicht da, landet sie in seiner Post |
| `/r <Text>` | Auf die letzte private Nachricht antworten |
| `/mail` | Dein Postfach |
| `/mail <Spieler> <Text>` | Schnell eine Nachricht in die Post schicken |

## Netzwerk

| Befehl | Was er macht |
| ------ | ------------ |
| `/hub` | Zurück in die Lobby |
| `/ot [Spieler]` | Spielzeit und erster Join |
| `/linkaccount <Name>` | Java- und Bedrock-Account verbinden |
| `/vote` | Link zur Vote-Seite |
| `/discord` | Link zum Discord |
| `/wiki` | Link zu diesem Wiki |
