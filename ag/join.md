# Auf MegaBuild.de verbinden

MegaBuild.de ist **crossplay-fähig**: Java- und Bedrock-Spieler spielen auf demselben Server zusammen.

{% hint style="warning" %}
Der Server ist aktuell im **Wartungsmodus**. Ein Verbindungsversuch zeigt dir dann eine Wartungsmeldung statt der Server-Liste. Das ist kein Fehler auf deiner Seite – aktuelle Infos gibt es auf [status.megabuild.de](https://status.megabuild.de/) und im [Discord](https://megabuild.de/dc/).
{% endhint %}

## Server-Adresse

<table><thead><tr><th width="220">Edition</th><th>Adresse</th><th width="120">Port</th></tr></thead><tbody><tr><td>Java Edition</td><td><code>megabuild.de</code></td><td>Standard (25565)</td></tr><tr><td>Bedrock Edition</td><td><code>megabuild.de</code></td><td><code>19132</code></td></tr></tbody></table>

Bei der Java Edition musst du **keinen Port angeben** – der Standardport wird automatisch verwendet.

## Anleitung

{% tabs %}
{% tab title="Java Edition" %}
{% stepper %}
{% step %}
#### Minecraft starten

Starte die Minecraft Java Edition in der neuesten kompatiblen Version. Welche Version aktuell unterstützt wird, erfährst du im [Discord](https://megabuild.de/dc/).
{% endstep %}

{% step %}
#### Zum Mehrspieler-Menü

Klicke im Hauptmenü auf **Mehrspieler** und anschließend auf **Server hinzufügen**.
{% endstep %}

{% step %}
#### Server eintragen

* **Servername:** MegaBuild.de (frei wählbar)
* **Serveradresse:** `megabuild.de`

Bestätige mit **Fertig**.
{% endstep %}

{% step %}
#### Beitreten

Wähle MegaBuild.de in der Liste aus und klicke auf **Server beitreten** – oder mache einen Doppelklick auf den Eintrag.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Bedrock Edition" %}
Bedrock deckt Handy, Tablet, Windows, Konsolen und die Nintendo Switch ab.

{% stepper %}
{% step %}
#### Zum Server-Tab

Gehe im Hauptmenü auf **Spielen** und dort auf den Reiter **Server**.
{% endstep %}

{% step %}
#### Server hinzufügen

Scrolle ganz nach unten und wähle **Server hinzufügen**.
{% endstep %}

{% step %}
#### Daten eintragen

* **Servername:** MegaBuild.de (frei wählbar)
* **Serveradresse:** `megabuild.de`
* **Port:** `19132`

Speichere den Eintrag.
{% endstep %}

{% step %}
#### Beitreten

Wähle MegaBuild.de unter deinen Servern aus und tritt bei.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
**Konsolen-Spieler:** Auf PlayStation, Xbox und Switch ist das Hinzufügen eigener Server je nach Plattform eingeschränkt. In dem Fall brauchst du eine der üblichen Drittanbieter-Lösungen (z. B. einen DNS-Dienst), um externe Server zu erreichen.
{% endhint %}
{% endtab %}
{% endtabs %}

## Es klappt nicht – was tun?

<details>

<summary>„Verbindung fehlgeschlagen" oder „Server nicht erreichbar"</summary>

1. Prüfe auf [status.megabuild.de](https://status.megabuild.de/), ob der Server gerade läuft oder in Wartung ist.
2. Kontrolliere die Adresse auf Tippfehler: `megabuild.de` – ohne `www.` und ohne `https://`.
3. Bei Bedrock: Ist der Port `19132` eingetragen?

</details>

<details>

<summary>„Outdated client" oder „Outdated server"</summary>

Deine Minecraft-Version passt nicht zur Server-Version. Stelle in deinem Launcher die aktuell unterstützte Version ein – welche das ist, steht im [Discord](https://megabuild.de/dc/).

</details>

<details>

<summary>Ich komme trotzdem nicht rein</summary>

Melde dich beim [Ticket-Support](https://megabuild.de/ticket/) oder im [Discord](https://megabuild.de/dc/). Beschreibe dabei möglichst genau:

* Java oder Bedrock?
* Welche Version?
* Welche Fehlermeldung erscheint (gerne mit Screenshot)?

</details>
