# Achievements

Besides the normal Minecraft advancements, there's a tab of its own called **“MegaBuild Sky”** with **20 achievements** around the airship, Mana, the skill tree and quests.

* Every achievement counts **once across the whole network**. If you got it on one island, you have it on all the others too.
* The first time, you get **3–8 Mana** – only in survival mode, and it counts towards the daily limit for [actions](economy.md#from-actions).

## How to see them

| | Java | Bedrock |
| --- | --- | --- |
| **List** | Advancements menu (key **L**), *MegaBuild Sky* tab | Command `/geyser advancements` |
| **When you earn one** | Pop-up at the top right and a chat message | Pop-up at the top and a chat message |
| **Language** | Your client's language | Always German – the German titles are listed below |

## Good to know

* **Touchdown** goes to the island owner – only they experience the intro.
* Skill tree achievements go to whoever buys the biome. The owner gets them the next time they enter their island.
* Just like in Minecraft, you can earn an achievement before the one that comes before it.
