# Discord

Next to the server itself, the Discord is the central place to go: announcements, support, feedback and chatting with other players. In-game, `/discord` (also `/dc`) gives you the link.

{% embed url="https://megabuild.de/dc/" %}

## Getting access

When you're new on the Discord, you only see a few channels at first.

{% stepper %}
{% step %}
#### Read and accept the rules

Read the rules and accept them with the button below.
{% endstep %}

{% step %}
#### Solve a short task

The bot gives you a small task to make sure you're not a bot.
{% endstep %}

{% step %}
#### Done

After that you see all channels. If you want to be pinged for news, get the **Info role** – with `/info` or the button. `/remove` takes it away again.

You speak English? Grab the **English role** with the button. You can translate any message with right-click (long-press on mobile) → Apps → **Translate** – only you can see it.
{% endstep %}
{% endstepper %}

## Linking your Minecraft account

Link your Minecraft account to Discord. Then rewards from the Discord – for bug reports, for example – go straight to your account in the game.

{% stepper %}
{% step %}
#### Get a code in-game

Type `/connect` in-game. You get a **6-character code** that's valid for 10 minutes.
{% endstep %}

{% step %}
#### Enter the code in Discord

In Discord, use `/connect code:YOURCODE` – or click **Enter code** in the linking channel.
{% endstep %}
{% endstepper %}

| What | In-game | In Discord |
| ---- | ------- | ---------- |
| View the link | `/connect status` | `/connect` without a code |
| Remove the link | `/connect disconnect` | `/disconnect` |

{% hint style="info" %}
This is not the same as linking your **Java and Bedrock accounts** – that's covered under [Linking accounts](connect-account.md).
{% endhint %}

## Tickets

For anything personal, open a **ticket** in the Discord – with the button in the matching channel. Only you and the team can see it.

| Ticket | What for |
| ------ | -------- |
| **Support** | Questions, problems with your account, reports of rule violations |
| **Bug bounty** | Reporting a bug on the server |
| **ClipCoin** | Submitting a video, a stream or a post about MegaBuild.de |

### Bug bounty and ClipCoin

Reported bugs and content about MegaBuild.de earn you a reward. The team rates it when closing the ticket:

| Bug bounty | Reward |
| ---------- | ------ |
| **Severe bug** – dupe, exploit, data loss, crash | 600 Mana + 200 Ruby |
| **Bug** | 250 Mana + 75 Ruby |
| **Cosmetic issue** | 50 Mana + 10 Ruby |

| ClipCoin | Reward |
| -------- | ------ |
| **Video or stream** | 500 Mana + 100 Ruby |
| **Post or idea** | 150 Mana + 30 Ruby |

* The reward goes **straight to your account**, plus a thank-you message in your in-game [mailbox](messages.md).
* For that, your Minecraft account has to be [linked](#linking-your-minecraft-account). If it isn't yet, the bot messages you – as soon as you link it, you get paid.
* Whether and how a report counts is up to the team.

{% hint style="warning" %}
**Exploiting bugs instead of reporting them** breaks the rules. Report bugs, especially dupes and exploits, only through a ticket – not in public.
{% endhint %}

## Private Talks

When you join the voice channel for creating one, you get your **own voice channel**. You control it with:

| Command | What it does |
| ------- | ------------ |
| `/lock` · `/unlock` | Close the channel or open it again |
| `/limit` | Set the maximum number of people |
| `/rename` | Rename the channel |
| `/adduser` | Bring someone into the closed channel |

## Levels

Writing in the Discord and spending time in voice channels earns you experience – there's a **chat level** and a **voice level**. At certain levels you get roles.

* `/rank` shows your rank card – or someone else's.
* `/top10` shows both leaderboards.

## All bot commands

| Command | What it does |
| ------- | ------------ |
| `/help` | Overview |
| `/ip` | Server address |
| `/vote` | Vote link |
| `/wiki` | Link to this wiki |
| `/invite` | Invite link to the Discord |
| `/socialmedia` | Our channels |
| `/info` · `/remove` | Get or give up the Info role |
| `/connect` · `/disconnect` | Link or unlink your Minecraft account |
| `/rank` · `/top10` | Rank card and leaderboards |

Every command also works with `!` instead of `/`, for example `!ip`.
