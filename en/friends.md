# Friends

Your friends list works across the **whole network**: the lobby and all islands share the same list. You can have up to **100 friends**.

## Adding a friend

{% tabs %}
{% tab title="By command" %}
```
/friend <player>
```

This works even if the player is currently offline.
{% endtab %}

{% tab title="By menu" %}
Open `/friend` and click **Freund hinzufügen** (Add friend). There you'll see all players who are currently online. Use the search to find players who are offline too: type part of the name in chat. Type `abbrechen` to cancel the search.
{% endtab %}
{% endtabs %}

If you've both sent each other a request, you're friends right away.

## Answering requests

`/friend requests` shows your pending requests. You can accept or decline them there. Players you decline don't get a message about it.

If you have a pending request when you log in, a chat message lets you know.

## Your friends list

In `/friend` you can see for each friend:

* **which server** they're currently playing on
* **since when** you've been friends

When a friend comes online, you get a short chat message.

**Ending a friendship:** Right-click the friend's head twice.
