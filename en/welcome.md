# Welcome to the MegaBuild.de Wiki

MegaBuild.de is relaunching as **Custom Skyblock** – with its own island generation, progression you can actually feel, and systems built for the long run. This wiki collects everything you need to get started and to understand how the server works.

{% hint style="warning" %}
**The server is currently in maintenance mode.**

No final release date for Custom Skyblock has been announced yet. For the current status, check [status.megabuild.de](https://status.megabuild.de/) and our [Discord](https://megabuild.de/dc/).
{% endhint %}
