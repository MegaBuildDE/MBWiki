# Commands

You reach most features through menus. These commands take you there directly.

## Skyblock

| Command | What it does |
| ------- | ------------ |
| `/sky` | **In the lobby:** create, join and manage your island. **On an island:** the island menu |
| `/quest` | Your quests |
| `/sky skills` | Skill tree – unlock new biomes |
| `/sky friends` | Members of your island |
| `/sky island` | Info about your island |
| `/sky stats` | Your statistics on this island |
| `/sky global` | Statistics for the whole server |

On other players' islands, `/sky stats` and `/sky global` require the **Statistics** right.

## Mana & Ruby

| Command | What it does |
| ------- | ------------ |
| `/bal [player]` | Balance – yours or another player's |
| `/baltop [mana\|ruby] [page]` | Richest players |
| `/pay <player> <amount>` | Send Ruby to a player |

Mana can't be sent – only Ruby.

## Friends & messages

| Command | What it does |
| ------- | ------------ |
| `/friend` | Your friends list |
| `/friend <player>` | Send or accept a friend request |
| `/friend requests` | Pending requests |
| `/msg <player> <text>` | Private message – if the player isn't online, it goes to their mailbox |
| `/r <text>` | Reply to the last private message |
| `/mail` | Your mailbox |
| `/mail <player> <text>` | Quickly send a message to someone's mailbox |

## Network

| Command | What it does |
| ------- | ------------ |
| `/hub` | Back to the lobby |
| `/ot [player]` | Playtime and first join |
| `/linkaccount <name>` | Link your Java and Bedrock accounts |
| `/vote` | Link to the vote page |
| `/discord` | Link to the Discord |
| `/wiki` | Link to this wiki |
