# Ranks

You can get a rank on MegaBuild.de and support the server at the same time.

{% hint style="warning" %}
**Rank perks for Custom Skyblock have not been finalised yet.**

The previous rank perks applied to the old CityBuild (plots, `/p merge`, plot flags and so on) and **no longer apply** to the new Skyblock. The new perks will be announced at launch and added here.
{% endhint %}

## Common questions

<details>

<summary>Do I keep my old rank after the relaunch?</summary>

How ranks from before the relaunch will be handled has not been announced publicly. Ask on [Discord](https://megabuild.de/dc/) or via a [ticket](https://megabuild.de/ticket/).

</details>

<details>

<summary>Does my rank apply to my Bedrock account too?</summary>

If you have linked your Java and Bedrock accounts, both share the same save.

{% content-ref url="connect-account.md" %}
[connect-account.md](connect-account.md)
{% endcontent-ref %}

</details>

<details>

<summary>My order hasn't arrived</summary>

Contact [ticket support](https://megabuild.de/ticket/) or email [support@megabuild.de](mailto:support@megabuild.de). Have your order or transaction number ready.

</details>

<details>

<summary>Can I buy ranks in game?</summary>

On the old CityBuild there was `/rshop` using in-game money. Whether something similar returns in Custom Skyblock has not been announced.

</details>
