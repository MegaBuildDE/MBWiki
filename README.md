# Willkommen im MegaBuild.de Wiki

MegaBuild.de relauncht als **Custom Skyblock** – mit eigener Inselgenerierung, spürbarer Progression und Systemen, die auf Langzeitspaß ausgelegt sind. Dieses Wiki sammelt alles, was du zum Einstieg und zum Verständnis der Server-Systeme brauchst.

{% hint style="warning" %}
**Der Server befindet sich aktuell im Wartungsmodus.**

Ein finaler Starttermin für den Custom Skyblock wurde noch nicht öffentlich angekündigt. Den jeweils aktuellen Stand findest du auf [status.megabuild.de](https://status.megabuild.de/) und in unserem [Discord](https://megabuild.de/dc/).
{% endhint %}
